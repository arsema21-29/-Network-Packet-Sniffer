# Network Packet Sniffer

A lightweight Python packet sniffer built with Scapy.

## Install dependencies
pip install -r requirements.txt

## Run (requires admin/root)
# Windows (run as Administrator)
python sniffer.py

# Linux/Mac
sudo python sniffer.py

## What it captures
- TCP packets
- UDP packets
- ICMP packets

## Disclaimer
Only use on your own network. Unauthorized sniffing is illegal.
